# Public candling dataset search — 2026-10-14

The best next acquisition check is **Egg Incubator's day tracker for rcnn**, because its published classes explicitly include Day 16 and Day 18. However, its species, physical egg identities, and incubation-label verification are undocumented. No newly located public source establishes a ready-to-train, independently identified duck Day 16 / Day 18 / Reject dataset, and no source guarantees 100% accuracy for this project.

This is a research result, not a training result. No dataset archive was downloaded, no training was run, and no publisher was contacted during this search. Image totals below are publisher-reported image counts, not verified counts of independent eggs. Public metadata visibility does not establish that an authenticated export will succeed.

## Existing sources are not new data

The project already records **THESIS Egg Candling v6**, **Pat Balut Eggs v8**, and **Team DevIn Duck Egg Candling v2** in `ml/sources/thesis-egg-candling.json`, `ml/sources/pat-balut.json`, and `ml/sources/duck-egg-candling.json`. The [September acquisition note](dataset-research-2026-09-12.md) records their download. Reimporting these sources or their augmented versions does not establish additional independent data.

The day tracker, THESIS segmentation project, and Roboflow MEGG source below were identified in the September note but are absent from those three source manifests. They are **previously known acquisition leads**, not discoveries claimed as new today. Bicol Balut Pinoy and the 2025 research collections provide additional leads with different limitations.

## Additional duck research lead

[Detection of Hatching Information of Meat Duck Eggs Based on Deep Learning](https://www.mdpi.com/2076-2615/15/23/3400), DOI 10.3390/ani15233400, reports 3,664 duck images, covering unfertilized, live embryonated, and abnormal eggs. Abnormal combines dead embryos and yolk-dispersed eggs. Indexed primary text reports collection typically at Day 12. Its [data availability statement](https://pmc.ncbi.nlm.nih.gov/articles/PMC12691155/) says data are contained within the article; no downloadable raw-image archive was verified. Direct full-page retrieval was blocked by rate limiting or a browser challenge, so these details were checked through indexed primary excerpts. This is an acquisition/contact lead, not an available Day 16/18 dataset. Raw-image licensing and egg-level metadata remain unresolved.

## Sources checked and excluded

- **[Dryad crested-ibis candling study](https://datadryad.org/dataset/doi:10.5061/dryad.fbg79cp9z)**: published June 5, 2026. Study reports 1,422 images from 98 eggs, with egg IDs, dates, incubation day and final outcomes. However, the actual downloadable record contains only three CSV files, a README and an R script, totaling **48.52 KB**. Raw photographs are absent, and species is crested ibis, not duck. Useful as a metadata/protocol example, not an image-training acquisition.
- **[SonyCookies/MEGG on GitHub](https://github.com/SonyCookies/MEGG)**: [recursive repository tree](https://api.github.com/repos/SonyCookies/MEGG/git/trees/master?recursive=1) has 29 JPG/PNG files, mostly UI assets, including seven testing pictures. [Training code](https://github.com/SonyCookies/MEGG/blob/master/ai-backend/scripts/train_model.py) points to a local `D:/4TH YEAR/CAPSTONE/MEGG/ai-backend/dataset` folder. No full training corpus or dataset license was found. Do not assume this GitHub repository is the same publisher as Roboflow MEGG.
- **[Quacklity Balut Incubator repository](https://github.com/J-Tabz21/-Quacklity-A-Smart-Balut-Incubator-with-Image-Processing-Based-Classification-of-Balut-Development)**: description promises documentation, code and data, but the repository is empty. **[GROUP-CGM-Thesis](https://github.com/lereias/GROUP-CGM-Thesis)** classifies shell visual properties into balut/penoy, salted-egg and table-egg uses; its code license does not make an unavailable candling/day corpus available.
- **Kaggle**: current [public candling search](https://www.kaggle.com/api/v1/datasets/list?search=candling) returns `mostefatabbakh/egg-fertility-1275` with license `Unknown`; [balut search](https://www.kaggle.com/api/v1/datasets/list?search=balut) returns no datasets. [Dataset Duck Egg](https://www.kaggle.com/datasets/rizkiramdhanhilal/dataset-duck-egg) still has a blank description in [owner metadata](https://www.kaggle.com/api/v1/datasets/view/rizkiramdhanhilal/dataset-duck-egg). Candling modality, age labels, and content permissions were not established. These are not verified replacements.
- **Mendeley/Zenodo lookalikes**: [BDEggs](https://data.mendeley.com/datasets/3766fb76w6/1) concerns exterior species recognition. [2026 machine-vision egg data](https://data.mendeley.com/datasets/49msr3ksxj/2) uses storage-day freshness classes (Day 0/25/45), not incubation age. No ready-to-import duck Day 16/18/Reject archive was verified on either service in this search. **[Bicol Balut Egg](https://universe.roboflow.com/bicol-university-orlm9/balut-egg)** remains unverified: search cards show age labels, but its project page could not be retrieved. Do not confuse it with the accessible Balut Pinoy metadata above.

## Decision

Audit day tracker first, then the THESIS segmentation overlap. Keep duck-status datasets separate unless their biological labels can be mapped explicitly. Request data and reuse terms from research authors only if the user authorizes contacting them.

For any acquisition, preserve the retained model and compare candidates on a frozen, independently identified group of eggs/batches. Group all views, ages, crops and augmentations of the same egg together. If egg identities are unavailable, report that limitation; duplicate clustering cannot prove egg independence. Report accepted accuracy, coverage and correct-over-all inputs separately. A perfect finite test score still does not guarantee 100% accuracy on future eggs.
