# Defense demonstration script

## Software-only demonstration available now

1. State the evidence banner: simulator/shadow only, no physical hardware or
   trained CNN.
2. Show the readiness blockers and eight empty view positions.
3. Run Day 16-like synthetic agreement. Open the stored inspection and show
   eight probability vectors, recorded age, version, canonical hash, audit, and
   pending outbox event.
4. Run low-confidence, bad-capture, age-mismatch, and device-fault scenarios;
   show that each becomes `REVIEW_RECAPTURE` for its explicit reason.
5. Run reject-suspect and read the warning that it is appearance-only and
   requires human review.
6. Append a synthetic reviewer disposition and show that the machine result and
   canonical hash did not change.
7. Disconnect or stop the API; show the web/mobile read failure does not invent
   readiness or a result.
8. Present the validation ledger and say which gates remain blocked.
